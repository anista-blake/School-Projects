# CS3354-Group-Project

### **Description**  
We created a **GUI Calculator** in Java to perform these basic arithmetic operations:  

- Addition
- Subtract
- Multiplication
- Division
- Clear (reset)

### **Requirements**
- Java 8 or later
- Gradle 7+
- MongoDB Atlas


### **How It Works**
- **Operation.java:** An abstract class defining basic operations and the calculate() method.
- **BasicOperation.java:** Implements the arithmetic logic.
- **InvalidOperatorException.java:** A custom exception that is thrown when an invalid arithmetic operator is entered by the user. 
- **CalculatorGUI.java:** The graphical user interface (GUI) interacts with the user to perform calculations.
